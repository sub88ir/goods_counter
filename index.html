사용 팁 & 스마트폰 연결 방법

💡 주요 기능 요약

  • 자동완성 기억: 한 번 입력한 품목명은 영구 기억되어 다음부터 초성이나 일부 글자만 쳐도 바로 뜹니다.
  • 연속 터치 최적화: 화면을 안 보고 + 버튼을 빠르게 연타해도 화면이 확대되지 않고 진동(안드로이드)과 함께 카운트됩니다.
  • 직접 수정: 숫자 칸을 터치하면 키패드로 즉시 원하는 수량을 입력할 수 있습니다.

🚀 GitHub에 올려서 내 폰에서 쓰는 법

  1. GitHub에서 새 Repository(저장소)를 만듭니다.
  2. 이 코드를 index.html 파일로 저장해 업로드합니다.
  3. 저장소의 Settings → Pages 메뉴로 이동합니다.
  4. Branch를 main으로 선택하고 Save를 누르면 1분 뒤 전용 웹사이트 주소가 생성됩니다.
  5. 스마트폰 브라우저(크롬/사파리)로 접속한 뒤 '홈 화면에 추가'를 누르면 실제 앱처럼 전체화면으로 편하게 쓸 수 있습니다!
